# 流程图教程与工作区布局

依据用户反馈，移除教程分幕演示、练习表单、模拟状态变化以及首次进入时弹出的体验向导；没有删除既有产品、来源或业务记录。CSV测试文件作为可选资料继续保留，不在教程中自动加载。

## 教程怎么读

侧栏“帮助·使用教程”选择模块：先看流程图，再按相同编号阅读入口位置、填写/检查内容、点击的按钮、操作后看到的结果。四模块分别为7、8、8、7步，共30步。矩形表示操作、菱形表示判断、实线表示下一步，虚线表示返回处理。资料不完整、来源不确定、正文与依据不一致等情况均有分支。

完整教程可以下载为Markdown。教程本身不写入业务数据，不替代人工查证，不把图中的“完成”当成真实审核结果。

## 工作区顺序

1. 产品资料：收集并保存有来源的候选，下一步去核对。收集入口与来源历史分开。
2. 数据核对：默认先显示待处理资料，之后查看确认结果与记录；操作说明放在独立标签页。先选字段和来源，再填依据并保存。
3. 内容工作台：先生成内容，再审核与导出；本轮到下载即可完成。后续有资料变化时才需要变更维护。
4. 变更追踪：先看受影响内容，更新正文或复核后保存新修订，再重新审核和下载。

页首显示当前环节、本页目标及下一去向；详细流程进度和跨模块快捷跳转默认折叠，避免重复导航挤占操作区域。每页说明中可直接跳转该模块完整教程。
