# 拟制案例演示操作

先按 README 启动。侧栏填写操作人，选择 P001 V1。全部资料为拟制，模板输出不计为真实模型结果。

1. 产品资料页点击导入拟制演示样例。查看批次记录与两条错误行；再次点击不重复导入。
2. 数据核对页选择净含量冲突组，查看200g、0.2kg和250g的来源。假设本次经营者核对包装为200g，排除250g并填写原因，再确认200g。继续确认名称和retail价格12元。
3. 内容工作台选择模板模式，分别生成商品介绍和朋友圈文案。查看完整输入快照及字段修订编号。提交审核，逐句核对并说明依据，通过后下载TXT。
4. 产品资料页手动补录price_cent=14.00、context=retail，说明新价单来源与调价原因。数据核对页确认采用新价格。
5. 变更追踪页查看两份内容被标为待复查，触发原因为同一零售价格修订。切换P002或P001 V2验证不串对象。
6. 按当前资料生成新修订；回内容工作台重新审核导出。查看历史修订仍保留12元的旧快照、原审核和导出记录。
7. 停止并重启应用，查看数据仍在。运行备份恢复检查，保留实际结果。

如需开箱演示已完成的场景，可先运行 `python -m scripts.demo_flow --out-dir runtime/my-demo`，再将QIANPIN_RUNTIME_DIR设为该目录并重启。脚本的确认与审核全部标为拟制脚本操作，实际使用须由人完成。

建议五分钟视频依次展示：用户问题、导入核对、生成审核、调价影响、实际测试与当前范围。视频需另行录制；本文不是已录制或已提交的证明。
