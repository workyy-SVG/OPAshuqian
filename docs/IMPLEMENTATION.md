# 实施范围与阶段记录

依据用户提供的《黔品智营详细开发与实施操作手册》，实现一个本地 Python 单体应用。

## 验收边界

- 固定一个演示品牌；以品牌、SKU、产品版本唯一识别商品。
- 六类字段，价格按渠道区分；原文、候选、确认修订、内容及审核均持久保存。
- 模板与 DeepSeek 模式明确区分；商品介绍与朋友圈文案两类输出。
- 内容保存全部输入依赖；修订时保守提醒，审核与导出重新检查依据。
- 首版不含自动电商发布、开放客服、多品牌入驻和句子级定位。
