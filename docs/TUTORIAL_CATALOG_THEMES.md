# 教程、分类目录与布局改进

## 使用入口

侧栏新增独立“使用教程”：每个业务模块均有功能作用、准备资料、具体按钮步骤、完成标志、常见问题与可视化练习；可下载Markdown说明。教程不修改业务资料。

侧栏“背景风格”提供山野青绿、晴空蓝白、暖杏纸笺、薰衣草紫、极简灰白五种风格，本次会话中跨页面保留；背景、侧栏、页头和主要按钮一起变化，成功/警告/错误状态含义不改变。

## 不知道商品条码时怎么选

产品资料默认进入“公开食品资料”，再进入“按分类挑选商品”。选择商品大类和细分类，点击“浏览这个分类”，按卡片挑选商品，使用上一页/下一页浏览。

- 熟食：即食餐食；水饮：饮料与饮用水。
- 生鲜：果蔬、肉类、蛋类、水产，逐个细分类浏览。
- 其他：零食、乳品、调味品。

每页最多12项，点击选择只展示候选预览；核对身份并确认导入后才保存到自己的SKU。导入后会选中目标SKU，接着去数据核对。条码/名称精确查询仍可用。公开分类由Open Food Facts维护，不等同于商家的库存，生鲜散装商品也可能没有记录。

这实现的是远程分类目录的按页浏览，**没有把全部条码和商品复制到应用数据库**。官方对超过几百项的大批量使用建议下载[离线数据导出](https://openfoodfacts.github.io/openfoodfacts-server/api/#rate-limits)；全库镜像需要额外的磁盘、索引和更新作业。本轮不在Streamlit请求里启动全库抓取。读取目录与名称查询共享每分钟8次进程限额，缓存1小时；网络失败保留当前页并提示重试。目录使用仍被支持的v2分类搜索接口，商品条码使用v3接口。

## 核对页的三段布局

1. “先看懂怎么核对”：先解释候选、冲突、确认资料，再列五步操作和示例，能跳转完整教程。
2. “开始逐项核对”：选字段 → 看来源卡片并选资料 → 确认处理方式、填写依据 → 保存。图表默认折叠，不会挡住主要操作。
3. “确认结果与处理记录”：看当前采用的资料，以及操作人、原因和处理历史。

200g和0.2kg同值；250g和200g不同。只有拟制样例预先设定250g为误录，真实商品不能套用这个结论。不确定时先补可靠来源，不以消除提示为目的随意确认。

## 其他布局调整

产品资料按“公开目录 / CSV / 手动补录 / 来源历史”分入口，完成情况和确认资料默认收纳。内容工作台把选择内容、选择生成方式、审核下载的顺序标清；变更追踪将维护/撤回操作折叠到单独区域，先展示待更新内容。
