## 启用公开拟制演示

本机默认行为保持不变。公开展示时，管理员显式配置：

```bash
export QIANPIN_PUBLIC_DEMO=true
export QIANPIN_LIVE_MODELS_ENABLED=false
.venv/bin/python -m streamlit run app.py --server.address=127.0.0.1
```

Streamlit Community Cloud 可在应用 Secrets 的最顶层（任何 `[deepseek]` 等分节之前）填写字符串：

```toml
QIANPIN_PUBLIC_DEMO = "true"
QIANPIN_LIVE_MODELS_ENABLED = "false"
```

管理员需要展示真实模型时，才把第二项改为 `"true"` 并配置提供方密钥。应用默认选择模板，不产生付费调用。显式 `QIANPIN_AUTH_REQUIRED=true` 或 `[access] required=true` 始终要求登录；Compose 默认仍启用登录。配置变更需要重启应用，不应复制真实密钥到源码。

公开模式使用 `runtime/demo-sessions/<会话>/<工作区>/` 的独立SQLite、来源、导出和日志，初始仅导入统一拟制样例，资料仍需人工确认。它不读取默认业务库，`QIANPIN_DB_PATH` 不会将沙盒指向正式数据库。侧栏“重置本次演示”确认后创建新工作区并清空页面选择，保留原文件和会话额度；不会删除原业务数据或操作全局额度库。旧沙盒保留在磁盘，管理员可在应用停止并完成必要归档后清理演示目录；没有自动清理任务。

额度库单独保存在 `runtime/model-quotas/quota.sqlite3`：每家模型全局每日100次请求，每会话两家合计每日3次，按北京时间零点切日。请求发出前在同一事务预留两层额度，失败和重试均消耗请求次数；达到上限时界面禁用生成，服务端也拒绝请求。重置工作区不会恢复额度。迁移004新增会话额度表，旧库升级前仍自动备份。

会话不是身份认证：新建浏览器会话可取得新会话额度，全局100次仍兜底。刷新、断线或重启可能丢失会话，不能保证日后找回资料。多实例不共享本地额度库。公开匿名演示只适合拟制资料；真实商家仍需账号授权、持久数据库和持久对象存储。本轮没有把原型改为商用多租户系统。

## 重置脚本

```bash
.venv/bin/python -m scripts.reset_demo --out-dir runtime/fresh-demo
QIANPIN_RUNTIME_DIR="$PWD/runtime/fresh-demo" .venv/bin/python -m streamlit run app.py
```

目标必须不存在，存在则拒绝覆盖。不要同时保留指向旧库的 `QIANPIN_DB_PATH`。脚本创建统一待核对样例；公开页面重置可直接使用侧栏按钮，无需脚本。完整自动确认、审核和备份演示仍使用 `scripts.demo_flow`，两者用途不同。
