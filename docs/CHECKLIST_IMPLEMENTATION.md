# 技术优化清单实施记录

依据2026-10-31用户提供的《黔品智营项目优化清单》V1.0实施。文档中的问题描述先按实际源码核验，再决定做法；保留本地单品牌业务边界，不把路线图自动变为多租户平台重构。

| 编号 | 处理方式与当前状态 |
| --- | --- |
| 1 迁移 | 已实现user_version、基线核验、连续SQL迁移、文件哈希、迁移前在线备份、失败事务回滚；尚不提供破坏性自动降级 |
| 2 初始化 | 已缓存无连接的Repository对象；产品列表按数据库变更标记缓存，成功操作后显式失效；确认快照与导出校验始终实时读库 |
| 3 认证 | 已实现对外监听自动启用登录保护、PBKDF2口令哈希、限次尝试、会话过期/退出撤销；受保护模式锁定操作人，下载时重新校验；实际公网HTTPS部署尚未执行 |
| 4 日志 | 已实现JSON事件、每日UTC轮转、14份保留、耗时与错误码；操作人只记摘要，不记录密钥、正文或来源资料 |
| 5 分层 | 已将视图中的查询统一下沉到query_service；测试防止视图重新出现SQL |
| 6 类型 | 已对新增核心接口及查询补充注解，mypy检查config、repository和全部services，检查未注解函数体；通过 |
| 7 覆盖率 | 64项测试通过，核心代码覆盖率92.24%，CI门槛80% |
| 8 单位 | 导入、人工文案与模型输出统一单位表，支持mg/毫克、斤/两、kg/g；补充边界与句子定位测试 |
| 9 重试 | 已实现可配置有限次数、指数退避、抖动与Retry-After；超过最大等待不提前重试 |
| 10 提示词 | 已抽取v1/v2文件和SHA256清单；任务保存具体版本，未知版本或内容被篡改时停止请求 |
| 11 CI | 已补macOS矩阵、Docker带哈希构建、容器内迁移/认证/单位测试和受保护容器健康检查；等待远端执行结果 |
| 12 并发 | 保留SQLite短事务、乐观修订冲突检查；补并发验证。迁移PostgreSQL为按需路线图 |
| 13 连接 | 缓存仓库对象，不跨线程共享可变SQLite连接，避免不安全的单例连接 |

| 15 定位 | 已在规则层提供异常句及起止位置，界面定位展示实施中；这不是句子级生成依赖 |
| 16 多品牌 | 作为后续产品路线图保留；本轮不开放多品牌入驻或跨品牌访问 |
| 17 定时 | 保留未来资料候选与人工确认规则，待补到期提醒查询，不自动替人确认事实 |
| 18 依赖哈希 | 已生成跨平台runtime/dev两份哈希锁，CI与Docker强制require-hashes和二进制安装；本机pip dry-run通过，干净环境验证继续执行；pip freeze本身不支持生成该锁 |

已核对官方资料：[Streamlit资源缓存](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_resource)、[Python SQLite](https://docs.python.org/3.13/library/sqlite3.html)、[pip安全安装](https://pip.pypa.io/en/stable/topics/secure-installs/)。缓存对象必须线程安全；事务连接按操作创建；依赖哈希由解析并编译锁文件的工具生成。
