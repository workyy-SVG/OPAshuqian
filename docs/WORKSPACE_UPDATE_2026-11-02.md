# 工作区缺陷修复与布局调整

## 修复的问题

- `services/import_service.py`：新建商品、基础资料批量补录在提交前检查全部字段。净含量等字段不合法时整次拒绝，避免只保存名称却提示成功。
- `views/product_view.py`：单项字段选择移到表单外，切换价格时立即显示渠道；表单按商品和字段隔离。新建商品入口清除旧的定向补录状态。
- `views/content_view.py`：生成草稿、编辑新修订、从变更追踪进入审核时，自动打开“审核与导出”并定位目标修订。
- `views/food_facts_view.py`：进入中文食品详情再返回，保留列表筛选和页码。
- `views/quality_view.py`：缺少必需资料且没有候选时，显示补录提示，避免仅给出绿色完成提示。

## 页面结构

| 模块 | 布局变化 | 主要源码 |
| --- | --- | --- |
| 统一页面 | 压缩标题区，合并重复流程导航为可点击入口；窄屏入口两列、统计紧凑排列 | `views/guidance.py`、`app.py` |
| 产品资料 | 默认手动补录，基础字段分栏；单项补录折叠；CSV、公开资料、来源历史分开；概览移到操作区后 | `views/product_view.py` |
| 公共选品 | 每页6项，支持搜索、分类及返回原列表状态 | `views/food_facts_view.py` |
| 数据核对 | 左侧来源候选，右侧处理方式与依据；小屏自动上下排列 | `views/quality_view.py` |
| 内容工作台 | 生成和审核分区；必需依据直接展示，长篇配料等折叠；生成后直接进入审核 | `views/content_view.py` |
| 变更追踪 | 待办处理、更新资料、变更记录三个页签；一次聚焦一份内容；正文与历史可展开 | `views/impact_view.py` |
