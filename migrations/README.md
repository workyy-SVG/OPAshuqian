# 数据库版本迁移

版本1为schema.sql基线，包括此前未标版本的完整首版数据库。启动时先核验旧库的表和列，符合基线后才登记为版本1；结构不符则停止，禁止静默猜测。

版本2增加查询索引。版本3增加按北京时间记录的模型每日调用计数。后续使用004_名称.sql等连续版本。迁移在BEGIN IMMEDIATE事务内执行，成功后更新PRAGMA user_version和迁移历史中的文件SHA256。已有历史文件被修改、版本超出程序支持范围或迁移失败时停止启动。

升级已有数据库前，使用独立只读连接和SQLite backup接口备份到runtime/backups。失败自动回滚当前事务；跨版本降级使用经过校验的备份恢复到新路径，不自动执行破坏性逆向SQL。请先在数据库副本上验证迁移，再更新正在使用的版本。
